# 검증 기록 — 2026-10-22

## 실제 실행 결과

- `npm test`: 25개 통과, 실패 0개.
- `npm run build`: 통과. 대상 safari15 / chrome100 명시.
- `IDEA_TEST_CHROMIUM_PATH=/tmp/chromium npm run test:e2e`: 5개 통과, 실패/건너뜀 0개, 약 74초.
- Chromium 실제 실행 버전 153.0.8010.0. 아이폰 Safari 15/갤럭시 Chrome 100/카카오톡의 사용자 에이전트와 375·390·430px 화면 크기를 모사했습니다. 해당 브라우저 엔진 자체를 실행한 것은 아닙니다.
- 브라우저 3개 컨텍스트를 서로 다른 기기로 사용했습니다. 외부 HTTP와 WebSocket을 차단하고 로컬 Edge 핸들러 → PGlite RPC로 연결했습니다. 운영 DB·운영 Edge·실제 배포에는 테스트 요청을 보내지 않았습니다.

| 항목 | 수정 및 실제 검증 | 한계 |
|---|---|---|
| P0-1 로그인 | 동일 IP에서 다른 토큰 실패와 강사 성공 분리, 30초 상한·전역 지연·기존 세션 유지, Edge의 IP 헤더 무시 | 실제 학교 NAT 환경 미검증. 기기 식별은 저장소 토큰 |

| P0-3 제출 취소 | 해당 회사에만 이전 내역 전달, 버전 변경 후 양식 복원, 수정·재제출·중복 방지, 마감 중 취소 거부 | 실물 폰 저장소 정책 미검증 |

서버 테스트는 기준 스키마와 기존 스키마+세 migration 적용 경로를 각각 분리 스키마에서 실행하고 ROLLBACK 후 스키마가 남지 않는지 확인했습니다. pgcrypto 확장이 없는 PGlite에서는 crypt/gen_salt/gen_random_bytes에 테스트 전용 대체 함수를 사용했습니다. digest는 PostgreSQL SHA-256을 사용합니다. 운영 pgcrypto 암호 강도·실제 권한 게이트웨이·Supabase 배포 자체의 검증은 아닙니다.

## 화면 및 수업 흐름 검증

- 네 칸 코드 입력, 붙여넣기, 자동 입장, 빈 플레이스홀더, 인앱 안내 표시.
- 학생에게 타사 결과·입장 코드 미전달, 자기 제출 요약, 취소 후 금액/이유 복원.
- 강사 준비/진행/회고/관리 탭, 수동 탭 유지, 고급 설정 접힘, 미제출 우선 정렬, 입장 제한 해제, +1분, 현황판 접속 표시.
- 390px에서 고정줄과 투자 마감 버튼이 화면 상단에 있고 높이 48px 이상. 이미 열린 더보기에서도 마감 후 취소 불가.
- 프로젝터 1920×1080, 1280×720에서 긴 회사 이름과 금액의 가로 넘침 없음, 이름 줄바꿈 스타일과 최소 24px 확인.
- 결과 공개 전 대기, 낮은 순위부터 발표하는 지연 순서, 오래된 공개 시각에서 연출 재실행 방지.
- 세 기기 흐름: QR → 코드 → 시작 → 두 기기 동시 제출 → 현황판 갱신 → 나머지 기기 오프라인/초안 복구 → 마감/공개/재개 → 취소/재제출 → CSV 두 종류 다운로드 → 6개 조 초기화.
- `test-results/`에 모바일·강사·현황판 캡처와 JSON 결과 생성(저장소에는 포함하지 않음). 실행 환경에 한글 폰트가 없어 캡처의 한글은 대체 사각형으로 표시됐습니다. DOM 문구와 치수는 검사했지만 한글 글꼴의 실제 줄바꿈·가독성 시각 검증은 완료하지 못했습니다.

운영 SQL, `tests/live.mjs`, 운영 초기화, Edge 배포, Vercel 운영 배포는 실행하지 않았습니다. 기능 브랜치의 코드이며 운영 적용은 README의 migration → Edge → 프런트엔드 순서를 따릅니다.
