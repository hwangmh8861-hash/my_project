# 아이디어 거래소

고등학생 창업 아이디어톤용 투자 앱. Vite로 빌드한 정적 프런트엔드, Supabase Edge Function/Postgres, Supabase Realtime을 사용합니다. 한 번에 하나의 수업을 운영합니다.

## 화면

- `/admin`: 4자리 비밀번호로 로그인하는 강사 화면. 초기 비밀번호는 소스에 포함하지 않습니다.
- `/s` 또는 `/student`: 회사 선택 후 투자하는 학생 화면.
- `/board#<전용 키>`: 강사 화면의 현황판 열기로 접속하는 보기 전용 현황판. 전용 키는 주소 해시에서 로컬 저장 후 제거됩니다. 학생에게는 `/s`만 공유합니다.

## 수업 순서

1. 강사 로그인 후 조 개수, 회사명, 조당 투자금, 타이머를 설정합니다.
2. 프로젝터에서 현황판을 한 번 열어 두고 QR을 표시합니다.
3. 조 대표가 회사를 선택합니다. 먼저 연결된 한 브라우저만 해당 회사를 사용할 수 있습니다. 같은 브라우저는 다시 접속하면 이어서 진행합니다.
4. 강사가 투자 시작을 누릅니다. 현황판과 학생 화면이 자동 전환됩니다.
5. 마감 후 결과와 회사별 투자 이유를 강사 화면에서 전환합니다. CSV는 총액과 상세 내역을 각각 내려받습니다.
6. 다음 수업 전에 CSV를 저장한 뒤 전체 초기화를 진행합니다.

기기 식별은 브라우저에 저장한 무작위 토큰으로 이뤄집니다. 시크릿 모드, 다른 브라우저, 브라우저 데이터 삭제는 다른 기기로 취급됩니다. 기기 변경은 강사의 연결 해제로 처리합니다. 회사 선택만으로 참여하므로 학생의 실제 소속을 자동 인증하지는 않습니다.

## 개발 및 배포

```sh
npm ci
npm test
npm run build
```

Vercel 프로젝트를 `hwangmh8861-hash/my_project`에 연결하고 Root Directory를 `idea-market`, Framework를 Vite로 지정합니다. 빌드 명령 `npm run build`, 출력 폴더 `dist`. Supabase publishable key는 브라우저에서 사용하도록 설계된 공개 키입니다. 서비스 키와 비밀번호는 프런트엔드나 저장소에 넣지 않습니다.

`supabase/schema.sql`은 새 DB용 기준 스키마입니다. 이미 운영 중인 DB에 전체 파일을 다시 실행하지 마세요. 운영 DB 변경은 Supabase migration 도구로 관리합니다. `supabase/edge.ts`는 `idea-market` Edge Function의 소스입니다. 요청은 자체 토큰 인증과 서버 검증으로 보호하므로 플랫폼 verify_jwt는 false입니다.

전용 `idea_private` 스키마는 외부 Data API 접근이 차단되며 RPC는 service_role에만 허용됩니다. 공개 Realtime 테이블은 수정 횟수만 알리고 투자 내역은 담지 않습니다. 클라이언트는 알림 후 권한에 맞는 스냅샷을 요청합니다. WebSocket이 끊기면 재연결하며 5초 폴링도 병행합니다.

서버의 마감 시각 이후에는 요청을 거절합니다. 별도의 DB 작업이 10초 간격으로 자동 마감 상태를 반영합니다. 현황판과 학생 화면은 서버 시각 보정 후 남은 시간이 0이 되는 즉시 입력을 잠급니다.

## 검증

`npm test`는 금액 단위와 투자 입력·CSV 검증을 실행합니다.
`tests/live.mjs`는 **테스트 전용 빈 수업에서만** 실행하는 실제 API/Realtime 수락 테스트입니다. `TEST_PIN` 환경변수가 필요합니다. 실제 수업이 진행 중인 DB에서는 실행하지 마세요.

실제 아이폰 Safari/갤럭시 Chrome, 학교 Wi-Fi/LTE 검증 여부는 별도 검증 기록을 확인해야 합니다. API 동시 접속 테스트는 실물 기기 검증을 대신하지 않습니다.
